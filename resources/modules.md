# [模块资源](https://root.wiki.gal.tf/resources/modules)

## 优质模块 [#优质模块]

[Latest File](https://latestfile.zip/module) 提供了一些模块，模块在精不在多，开心是最重要的，但是也不能胡来喔

<Callout title="小小的免责声明">
  并不是所有模块都可以无脑刷入，也不保证所有模块都能够适配所有机型
</Callout>

> 大部分人可能会选择在酷安这样的社区寻找模块，但是作为体量较大的社区，鱼龙混杂，很多模块的质量堪忧，就算收费的也不在例外
>
> 有些模块表面好用，但是质量问题带来的副作用也是不容小觑的，只能说杜绝无脑杜绝跟风，不能被舆论所左右，按需善用才是明道

## 多功能软件 [#多功能软件]

[苏柚](https://shirosu.gal.tf/utils) 是一个多功能软件，主打存储优化方面，也有不少的小功能可用

## 便用的 ROOT 管理器 [#便用的-root-管理器]

[SSU Compat](https://shirosu.gal.tf/compat) 是一个第三方 ROOT 管理器，旨在优化 ROOT 使用体验
